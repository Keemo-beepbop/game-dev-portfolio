Project Case Study

Every Second Counts

2D Mystery Horror Puzzle Game

Overview

Every Second Counts is a 2D mystery horror puzzle game made in C++ using Visual Studio. The visuals are created entirely using ASCII art. The player takes the role of a tired worker who returns home, only to become trapped in a deadly time loop where each death reveals new knowledge for the next attempt.
